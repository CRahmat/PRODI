Pertanyaan yang Sering Ditanyakan

Apa perbedaan Level 1, Level 2, dan Level 3?

Level 1 (Rp20.000) berisi worksheet coding dasar & motorik: mewarnai sesuai kode, menghubungkan garis, coding arah & bentuk, menyusun kata. Level 2 (Rp20.000) berisi worksheet matematika & logika: penjumlahan, pengurangan, matematika bentuk, logika geometri, koordinat. Level 3 (Rp20.000) berisi worksheet logika lanjut: logika pola, operasi pola gambar, bangun ruang, menemukan koordinat.

Apa itu Paket All In + Bonus dan All In + Reseller?

All In + Bonus (Rp50.000) menggabungkan Level 1, 2, dan 3, ditambah bonus modul TK/PAUD, 54 Lembar Aktivitas Tambahan, cerita bersuara, 8 games edukasi, tracing, maze, puzzle & crossword. All In + Reseller (Rp75.000) berisi semua itu, ditambah hak jual ulang sesuai lisensi, template landing page, tutorial setup landing page, dan free konsultasi.

Saya sudah beli Level 1/2/3, bisa upgrade ke All In?

Tentu bisa. Silakan hubungi WA support agar dibantu proses upgrade ke paket All In + Bonus atau All In + Reseller.

Cocok untuk usia berapa?

Dirancang untuk anak usia 3-9 tahun, mulai jenjang TK/PAUD (bonus paket All In) hingga Level 3. Materi bisa Bunda sesuaikan dengan kemampuan dan usia si kecil.

Apakah Bunda perlu bisa coding untuk mendampingi anak?

Tidak perlu. Semua worksheet dilengkapi instruksi bergambar yang mudah diikuti, jadi Bunda tetap bisa mendampingi anak walau tidak punya latar belakang coding.

Apakah ada biaya bulanan atau perpanjangan?

Tidak ada. Pembayaran dilakukan satu kali di paket manapun yang dipilih, dan akses produk menjadi milik Bunda selamanya. Tidak ada langganan bulanan, tidak ada biaya perpanjangan.

Apakah produk berbentuk fisik?

Tidak. Produk digital berformat PDF (dan audio untuk cerita bersuara). Setelah pembayaran berhasil, Bunda bisa langsung download dan cetak sendiri di rumah, kapan pun dibutuhkan tanpa batasan jumlah cetak.

Bagaimana cara mengakses produknya?

Link download akan langsung dikirim melalui email atau tampil di halaman terima kasih setelah pembayaran terverifikasi. Akses bisa Bunda buka kembali kapan saja.

Apakah games edukasinya aman untuk anak?

Ya, 8 games edukasi dalam paket All In berlisensi resmi dan dirancang khusus untuk anak-anak, sehingga aman dan bebas konten yang tidak sesuai.

Apakah worksheet dapat dicetak berkali-kali?

Bisa. Worksheet berbentuk file PDF yang dapat dicetak ulang sesuai kebutuhan, bahkan untuk adiknya kelak, tanpa batasan jumlah cetak.

Apakah ada garansi jika filenya bermasalah?

Ada. Jika file rusak, tidak bisa diakses, atau tidak sesuai deskripsi, hubungi admin maksimal 1×24 jam setelah pembelian untuk penggantian file atau pengembalian dana.

Apakah produk bisa digunakan oleh guru dan bimbel?

Cocok. Paket ini bisa menjadi bahan pendukung untuk guru PAUD, TK, tutor, hingga pemilik bimbingan belajar kecil. Bila ingin menjualnya kembali, ambil paket All In + Reseller sesuai ketentuan lisensi.

Hak jual ulang hanya berlaku untuk paket All In + Reseller, sesuai aturan lisensi yang berlaku. Aturan lengkap akan diberikan setelah pembelian.

Pertanyaan yang sering ditanyakan

Apakah ini produk digital atau fisik?

Produk digital berformat PDF (dan audio untuk dongeng). Setelah pembayaran berhasil, file bisa langsung diunduh dan dicetak sendiri di rumah tanpa batas jumlah cetak.

Cocok untuk usia berapa?

Dirancang untuk anak usia 3-9 tahun, mulai jenjang TK/PAUD hingga Level 3. Materi bisa Bunda sesuaikan dengan kemampuan dan usia si kecil.

Apakah Bunda perlu bisa coding untuk mendampingi anak?

Tidak perlu. Semua worksheet dilengkapi instruksi bergambar yang mudah diikuti, jadi Bunda tetap bisa mendampingi anak walau tidak punya latar belakang coding.

Apakah games edukasinya aman untuk anak?

Ya, 8 games edukasi dalam paket Lengkap + Bonus berlisensi resmi dan dirancang khusus untuk anak-anak, sehingga aman dan bebas konten yang tidak sesuai.

Apakah ada garansi/refund jika filenya tidak sesuai?

Ada. Produk berupa file digital — jika file rusak, tidak bisa diakses, atau tidak sesuai deskripsi, hubungi admin maksimal 1×24 jam setelah pembelian untuk penggantian file atau pengembalian dana.

Setelah bayar, filenya dikirim ke mana?
